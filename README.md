# Fast Edith · installateurs

Ce dépôt contient uniquement les installateurs de **Fast Edith** (le code de l’outil est privé).

- Télécharger la dernière version : [Releases](https://github.com/Fulberitodesign/fast-edith-releases/releases/latest)
- Windows : `Fast-Edith-Setup.exe` · Mac : `Fast-Edith-Setup.dmg`
- Site : https://fast-edith-app.netlify.app

Un compte Fast Edith est nécessaire pour utiliser l’outil. Les mises à jour s’installent automatiquement.
